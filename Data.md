## Data

The `data/` folder contains the essential files for the project:

### 1. FITS Files
- Simulated galaxy images for demonstration purposes.
- Filenames follow the pattern:
  - `spiral_0.fits`, `spiral_1.fits`, … for spiral galaxies
  - `elliptical_0.fits`, `elliptical_1.fits`, … for elliptical galaxies
- Each FITS file includes PSF blurring, Gaussian noise, and a small weak lensing shear.

### 2. Shape Measurements CSV
- `shape_measurements.csv` contains quantitative measurements for each galaxy:
  - `file` : Name of the FITS image
  - `g1`, `g2` : Shear components
  - `e` : Ellipticity
  - `sigma` : Moment-based size estimate

### Notes
- The `data/` folder contains a **small subset** of all simulated galaxies for demonstration purposes.
- The **full dataset** can be regenerated by running the provided Colab notebook.
